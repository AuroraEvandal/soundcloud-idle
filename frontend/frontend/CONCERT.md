# Спаси концерт

Полный серверный режим SoundWave: шесть сюжетных смен с решениями, постоянным оборудованием и выплатами в основной кошелёк. Демо-экономика удалена. Вход через Telegram; отсутствие авторизации/сервера показывает ошибку, не подменяется локальным прогрессом.

## Игра

В новой попытке 18 сцен. Сохранённые попытки из 12 сцен можно закончить. Девять типов: частота, уровень, пэды, сведение, свист, команда артиста, коммутация кабелей, память при блэкауте и питание. Поздние смены добавляют движущиеся узкие зоны, двойные задачи и последовательности до семи действий. Серии кнопок собираются без ожидания сети между нажатиями и проверяются сервером целиком.

На клиенте — звук, органы управления и анимация. Сервер создаёт задания, проверяет порядок и удержание по своим часам, определяет ранг и награду. Результаты, покупки и переходы атомарны. Клиент отправляет только ID действий, не оценки или деньги. Неопределённые запросы сохраняются с UUID и восстанавливаются перед загрузкой состояния.

За B/A/S: 30/45/60 монет и 10/15/20 опыта. Первый успех в смене +50; первая серия шести действий в ней +25. До пяти успешных оплаченных концертов в сутки UTC, затем можно продолжать сюжет без денежных выплат/опыта. C не платит и не открывает следующую смену. Стартовых демоденег и платы за вход нет.

## Запуск и выпуск

`npm run dev` из этой папки; вход в основной игре через «Концерт». Отдельная страница `/concert.html` тоже требует Telegram initData. Формат запросов — в `../../docs/api.md`, раздел «Концерты v1».

БД: `supabase/migrations/20261108140141_concert_career.sql`, затем Edge Function `concert`, затем frontend. Прямой доступ anon/authenticated к таблицам и RPC запрещён; Edge проверяет Telegram-подпись. Оборудование покупается за основной баланс. Звук использует существующие сэмплы BeatLab и синтезатор; записанного вокала и озвучки диалогов пока нет.

Поправка сетевого удержания: `20261108141236_concert_hold_network_tolerance.sql`.

## Проверка

- Frontend: `node --test --test-concurrency=1 tests/*.test.mjs`, `npm run build`.
- Backend из `supabase/`: `npm test`, Deno check функции concert.
- PGlite проверяет реальные миграции, 18 сцен и прежние попытки из 12 сцен, выплаты/уровни, покупки, лимит, чужие ID, повторные запросы, паузу и удержание.
- Браузерный прогон с реальной SQL-логикой: все девять механик, S, +135 монет/+20 опыта, покупка, сохранение и восстановление. Проверены 320/390 px. Сценарии и снимки — в `output/playwright/`.
- `supabase/tests/concert-live-smoke.sql` — проверка production RPC в транзакции с обязательным ROLLBACK; тестовые изменения не сохраняются.

Автоматизация известных QTE всё ещё возможна: выплаты ограничены серверным временем, порядком действий и суточным лимитом. Физический iPhone/Telegram, медленная мобильная сеть и субъективная сложность поздних смен требуют плейтеста. Пауза на сервере ограничена двумя минутами; после неё пропускается текущая сцена, попытка сохраняется.

Проверка выпуска: 64 frontend-теста, 69 backend-тестов, production build и Deno check прошли. После патча повторно проверен production RPC под service_role с ROLLBACK: 12 сцен, +135 монет/+20 опыта, покупка и повторы без двойного начисления. Браузерный тест обрывал ответ уже после коммита next и подтверждал восстановление после перезагрузки без зависания/пропуска следующей сцены.
