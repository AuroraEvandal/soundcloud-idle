# Инструкции для фронтенда

Приложение находится в этой папке (`frontend/frontend/` относительно корня репозитория). Для Vercel используйте её как Root Directory.

Перед изменениями сверяйтесь с `../../docs/game-design.md`, `../../docs/api.md` и `../../backend/schema.sql`. Соблюдайте общие правила из `../../AGENTS.md`.

Запускать команды npm нужно из этой папки. Требуется Node.js 22.12 или новее.
