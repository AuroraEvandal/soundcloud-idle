# SoundWave: фронтенд

Telegram Mini App, симулятор рэпера. Vite + React (обычный JavaScript), без лишних библиотек.
Оформление: ультра-тёмный плоский iOS-стиль (палитра и правила в `src/styles.css`, переменные вверху файла).

## Запуск

Нужен Node.js 20.19+ (или 22.12+).

```
cd frontend
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка сборки
```

Игра работает без ключей и вне Telegram: все запросы идут на фейковый сервер внутри `src/api.js`.

## Как устроено

- `src/api.js` единственное место, где есть обращения к серверу и игровая логика мока.
  Функции `login`, `getProfile`, `getHand`, `startBattle`, `submitRound` повторяют форматы из `docs/api.md`.
  Переключатель `MOCK` по каждой функции: `true` фейк, `false` настоящий Supabase.
- `src/supabase.js` создаёт клиент, только если есть `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (см. `.env.example`).
- `src/errors.js` таблица ошибок (коды из `docs/api.md`) и тексты для игрока.
- `src/screens/` экраны: вход по нику, рабочий стол, SoundWave (лента и батл), Студия, Колода и паки, ТГ, Профиль, Магазин.

## Вход по нику

Первый экран просит ник (2-16 символов). Он хранится в `localStorage` (`sw_nick`) и показывается
на рабочем столе, в арене батла, ленте, ТГ и профиле. Кнопка «Сменить ник» в профиле возвращает на вход.
В `docs/api.md` у `login` пока нет поля для ника, поэтому на настоящий сервер он не уходит
(предложение для бэкенда: добавить в `login` необязательное поле `nickname`).

## Что работает по API, а что пока заглушка

Работает на данных `api.md`: вход, профиль, соперники с замками по популярности, батл из 3 раундов
(победа после 2 выигранных), 4 слота `setup, development, boost, punch`, рука 4-6 карточек на слот,
оценка по 4 критериям, ничья, награды (опыт, популярность, уровень), лимит оценок `ai_requests_left`,
обработка всех кодов ошибок.

Новые механики (на моке, формат запросов в `API-PROPOSAL.md`, ждут согласования с бэкендом):
сниппеты в Студии (тапы -> хайп -> прослушивания, монеты, популярность), биты, оборудование (бонус к доходу),
гардероб и каталог одежды с бонусами, паки (рулетка, редкий дроп одежды), колода из купленных карточек.

Каталог вещей, цен и бонусов лежит в `src/mockCatalog.js`. Это заглушки: сюда (а потом в таблицы БД) вносятся настоящие вещи.
Картинки одежды: PNG-слои в `public/clothes/`, путь пишется в поле `image`.

Остались заглушками: ответы в ТГ-чатах (сообщений от сервера в API нет).

## Известная дыра API

`get-hand` не возвращает номер раунда и тему, поэтому после перезапуска посреди батла продолжить раунд нельзя.
Фронт хранит только `battleId`, при запуске проверяет его и сбрасывает.
Предложение для бэкенда: добавить в ответ `get-hand` поля `round` (номер и тема) и счёт раундов.
