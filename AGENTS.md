# Проект: симулятор рэпера (Telegram Mini App)

Игра, где игрок собирает строчки из карточек, получает оценку сервера, побеждает ботов в баттлах и растёт в уровне и популярности. Российская сцена, вымышленные персонажи, мат с цензурой.

## Структура репозитория

- `frontend/frontend/` : мини-апп (Vite + React). Работает друг.
- `backend/` : Supabase (SQL-схема, Edge Functions на TypeScript). Работаю я.
- `docs/` : документация.

## Сначала прочитай эти файлы

- `docs/game-design.md` : правила игры.
- `docs/api.md` : договор между фронтом и бэкендом (форматы запросов и ответов, коды ошибок, принятые решения).
- `backend/schema.sql` : структура базы данных.

## Правила работы

1. **Работай только в своей папке** (`frontend` или `backend`), если тебя явно не попросили иначе.
2. **Не меняй формат API молча.** Если нужно изменить запрос или ответ, сначала правится `docs/api.md`, и об этом говорится людям.
3. **Фронт присылает только ID** (карточек, батла, соперника). Тексты, оценки, очки, опыт всегда считает сервер.
4. **Игровую логику не держи в браузере.** На клиенте только интерфейс и временное состояние экрана. Все обращения к серверу идут через один файл `frontend/frontend/src/api.js`.
5. **Секреты:** токены и ключи только в `.env` (локально) и Supabase Secrets (на сервере). Никогда не коммить их и не вписывать в код. Ключ `service_role` используется только в серверных функциях, во фронте допустим только `anon`.
6. **Оценка раунда:** ИИ-судьи в MVP нет, всё считает код на сервере. Рифма и флоу — алгоритмы; панч — из редкости и бонуса карточки в слоте «панч»; смысл — из таблицы связей тем `theme_relations` (заполняет автор игры).
7. **Маленькие шаги.** Делай небольшие изменения, после каждого рабочего предлагай сделать commit.
8. **Люди в проекте новички.** Объясняй простыми словами, что именно ты изменил и как это проверить.

## Принятые числа

- Опыт до следующего уровня: `round(100 * 1.1^(level - 1))`.
- Победа в батле: +25 опыта, +15 популярности, +50 монет.
- Старт игрока: 300 монет, бесплатный «Бит 1».
- Сниппет: релиз каждые 20 хайпа; монеты = стримы/10; стримы = base_streams(бита) × (1 + min(фанаты, 400)/200) × (1 + доход%/100). Каталог цен — в `docs/game-design.md` раздел 8 и `docs/api.md` (Экономика v0.2).
- Поражение: -10..15 опыта, -5..10 популярности (ниже 0 и ниже порога открытой локации не падает, уровень не понижается).
- Рука: ровно 4 карточки на каждый из 4 слотов (setup, development, boost, punch), только рабочие (`uses_left > 0`).
- Лимит карточки: 3 боя, после чего она сгорает (не выдаётся в руку, в колоде видна как сгоревшая).
- Ник игрока берётся из Telegram и синхронизируется при каждом входе.
